# TRANSERA 2.0 — тестовая версия

Отдельная тестовая версия логистического приложения. Оригинальные репозитории не изменяются.

## Возможности
- Собственный и наёмный транспорт
- Стоимость, себестоимость и прибыль
- Рейсы и статусы, сохранение в IndexedDB
- Экспорт и импорт резервной копии JSON

## Запуск
Откройте index.html в современном браузере (для IndexedDB рекомендуется локальный HTTP-сервер или GitHub Pages).

## Публикация
Workflow `.github/workflows/deploy.yml` публикует статический сайт через GitHub Pages. В настройках репозитория Settings → Pages необходимо выбрать Source: GitHub Actions, если ещё не выбрано.

## Ограничения
Это тестовый прототип без авторизации и синхронизации устройств. Плановые и фактические расходы не заменяют бухгалтерский учёт. Перед коммерческим использованием требуются дальнейшее тестирование, защита данных и серверная часть.
